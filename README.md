# Restaurant Sales Analysis

## Overview
An Excel dashboard project focused on analyzing restaurant sales and order performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Dashboard

## Data Cleaning
- Checked and removed duplicate records.
- Checked missing and incorrect values.
- Standardized data formats.
- Verified sales, order, branch, and payment data.

## Dashboard
- Total Sales and Total Orders
- Branch-wise Sales
- Channel-wise Sales
- Category and Product Analysis
- Payment Method Analysis

## Key Insights
- Jumeirah recorded the highest sales among all branches.
- Total sales reached AED 295,881.65.
- A total of 3,600 orders were recorded.
- Dine-In generated the highest sales among all channels.
- Mains was the highest-performing category.
- Mixed Grill was the top-selling food item.
- Card was the most commonly used payment method.
